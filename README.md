# Neethu Premanathan's Portfolio

A modern, responsive personal portfolio website for Neethu Premanathan, Senior Java Backend Engineer.

## Live Demo
Once deployed, this will be available at [https://neethu44.github.io/portfolio/](https://neethu44.github.io/portfolio/)

## Built With
- **HTML5** (Clean, semantic structure)
- **CSS3** (Modern, dark-themed responsive design)
- **Google Fonts** (Inter and Outfit)
- **Font Awesome** (Professional icons)

## Sections
- **Hero / Header**: Introduction and tagline.
- **About Me**: Professional summary with 8+ years of experience.
- **Skills**: Technical expertise in Backend, DevOps, APIs, and Tools.
- **Projects**: Showcase of professional works and contributions.
- **Contact**: Reachable via Email, Phone, and LinkedIn.

## Deployment Notes
Designed specifically for **GitHub Pages**. For best results, use the provided assets in the `images/` directory.
